Content editor

This editor runs locally, not on the deployed site.

The CMS behind this site is Decap, a git-based editor: an author writes in a normal rich-text UI, and publishing commits Markdown to the repository. That commit triggers a rebuild, so content ships without a developer involved.

Why there is no login here

Decap's git-gateway backend authenticates through Netlify Identity, which is no longer available on Netlify's free tier. The alternative is a GitHub OAuth app, which means running a small auth service. Neither is needed to demonstrate the editor, so this deployment simply doesn't enable one.

Running it locally needs no accounts, no network, and no login at all:

npm run cms   # CMS backend on :8081
npm run dev   # the site on :4321

Then open localhost:4321/admin/. The editor reads and writes the real Markdown files in src/content/blog/ — saving a post writes a file, and the dev server hot-reloads it.
